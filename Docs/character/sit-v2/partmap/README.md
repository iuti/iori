# 塗り分けの地図(下書き)

最終版の全画素を、ちょうど 1 つの部位に割り当てた地図。人形のレイヤーは、これからこの地図で最終版を切り出して作る(色で振り分けるのはやめる)。

- `partmap_draft.psd`: クリスタで開く用。いちばん下が最終版(下敷き)、その上に部位ごとのレイヤー(単色、レイヤーの不透明度 55%)。
- `preview.png`: 最終版に地図を重ねた絵。
- `labels.png` / `labels.json`: 地図そのもの(画素の値 = 部位の番号)と部位の一覧。

今の振り分けから作った下書きなので、まちがいがある。分かっているもの:
- 首・ヘッドホン(neck)は四角い箱で切っただけ
- 椅子の背と布は、ジャケットのふちで少し取り残しがある
- 口は楕円で切っただけ
- 毛束の境目は、今の振り分けのまま

## 直し方

1. 部位のレイヤーを選び、そのレイヤーの色(スポイトで取る)で、その部位の所を塗る。ちがう部位の所は消しゴムで消す。
2. 1 つの画素は、ちょうど 1 つの部位のレイヤーにだけ塗られていること(重ならない、すき間もない)。背景も「00 背景」に塗る。
3. 境目は線画の線に沿って。毛束の線や輪郭線は、手前にある部位に入れる(前髪の線は前髪、あごの線は顔)。
4. ふちの半透明はいらない。べた塗り(アンチエイリアスなし)でよい。やわらかいふちは、あとでこちらで作る。
5. 部位を増やしたいときは、新しいレイヤーを足して名前を付ければよい(例: 「20 マグ (mug)」)。
6. レイヤーを結合しないで、PSD のまま保存する。

隠れている所(髪の下の首、顔の下のあご、後ろ髪の続きなど)は、この地図には入れない。地図ができたあとで、部位ごとに描き足しが要る所を図にして相談する。
