軸の目安: 首の軸 (575, 345)、体の軸 (585, 885)。頭の傾きは最終版のまま。model.json の `"x-iori": {"head_tilt": 度, "body_pivot": [585, 885]}` に入れる(head_tilt は切り出しのときに目と口の線から測る)。

要る動き: まばたき、呼吸、髪と揺れもの、首を小さくかしげる、視線、口パク、体を少し揺らす・傾ける。眉、表情の差分、全身の動きは作らない。

## スキルの決まりと違う所(と理由)

- **canon(正面向きに描き直す)をしない。** 最終版の形を変えないため。顔は斜め向きで傾いたまま、Unity 側の `head_tilt` で軸を合わせる。
- **脚と椅子を 1 枚の動かない土台にする。** 前回、GPT Image が素足の切り抜きを断ったので、脚の単独描画を頼まない。
- **垂れたストラップは bottom_y より下にある。** 土台のままにするか、body のチェーンとして揺らすかは、ランタイムの作りによる(要相談)。揺らすなら、ストラップの後ろを描き足す。
- **手とマグは body に入れる。** マグがひざ(土台)の上に乗っているので、体を揺らすと手がひざの上を少し滑る。揺れを小さく保つか、手とマグだけ動きを弱める(チェーン、または別の重み)。
- **眉は face に描き込んで、眉レイヤー(brows)は作らない。** 表情の差分を作らないため。
- **i2i は途中で掛けない。** スキルは段階ごとに clean.py を掛けるが、今回は chico の指示で、一番最後に画面に出すパーツにだけ掛ける。
- **テクスチャは PNG。** Unity は WebP を読めないため。
